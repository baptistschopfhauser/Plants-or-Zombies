🎨 Bloomguard Art Studio

Developer tool: not part of the game. Prepare original artwork, preview it in place, export it at the right size.

Export normalised PNG: trims empty space, scales to the standard height (512 px for characters, 1008 × 590 for lawns), puts the feet or root on the bottom-centre, and names the file for you. Drop the exported file in www/sprites/<group>/ and paste the JSON line into www/sprites/sprites.json.
